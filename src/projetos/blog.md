# Blog

## Laboratório de Spec-Driven Development

Blog fullstack criado como projeto de teste para explorar na prática como o **Spec-Driven Development (SDD)** funciona: escrever a especificação primeiro — requisitos, comportamento e critérios de aceite — e só então partir para a implementação.

Por ser um domínio conhecido (posts, listagem, leitura), o blog é o cenário perfeito para focar no processo em vez do produto: dá para avaliar o quanto uma boa spec acelera o desenvolvimento e reduz retrabalho.

## Contribuições principais:

- **Fluxo SDD completo:** Especificação de cada funcionalidade antes do código, validando o ciclo spec → implementação → verificação

- **Fullstack do zero:** Desenvolvimento do frontend e do backend do blog, da modelagem de conteúdo à renderização das páginas

- **Aprendizados documentados:** O próprio projeto serve de referência sobre o que funciona (e o que não funciona) no desenvolvimento guiado por especificação
