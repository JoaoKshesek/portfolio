# LIDE Global

## Plataforma de Conexão para Líderes Empresariais

A LIDE é a maior e mais influente organização de líderes empresariais da América Latina, unindo mais de 2 mil empresas e 4 mil líderes em todo o mundo. O LIDE Global é uma plataforma digital que conecta esses líderes, facilitando networking, compartilhamento de conhecimento e oportunidades de negócios.

O projeto começou como LIDE Paraná e escalou para uma plataforma global, transformando-se em um ecossistema digital robusto para toda a rede de líderes.

## Contribuições principais:

- **Desenvolvimento do backend:** Arquitetura e implementação da API que suporta toda a plataforma, garantindo escalabilidade para milhares de usuários simultâneos e integração com múltiplos serviços

- **Painel administrativo:** Criação de um sistema completo de gestão administrativa que permite controlar eventos, membros, permissões e configurações da plataforma

- **Aplicativo mobile:** Desenvolvimento do aplicativo mobile que leva a plataforma LIDE para os dispositivos dos líderes empresariais, permitindo acesso em qualquer lugar

- **Liderança técnica:** Liderou uma equipe de desenvolvedores mobile na implementação de features críticas, coordenando sprints, code reviews e garantindo qualidade de código
