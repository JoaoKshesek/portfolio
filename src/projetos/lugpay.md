# LugPay

## Aplicativo de Pagamentos

Aplicativo mobile de pagamentos desenvolvido para a JMN, construído **do zero** em React Native com backend em Node. Do primeiro commit à publicação, o projeto cobriu a definição da arquitetura, o desenvolvimento das telas e a integração com os serviços de pagamento.

## Contribuições principais:

- **Desenvolvimento do zero:** Construção do aplicativo desde a concepção, definindo arquitetura, navegação e padrões de código

- **Fluxos de pagamento:** Implementação das telas e integrações dos fluxos de pagamento do app

- **Integração com backend:** Consumo das APIs em Node, com tratamento de erros e estados de carregamento consistentes

- **Publicação:** Preparação do app para distribuição nas lojas
